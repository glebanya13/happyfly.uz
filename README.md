# ✈️ Happy Fly Travel & Logistics (happyfly.uz)

Официальный веб-сайт туристического и логистического агентства **Happy Fly** (Ташкент, Узбекистан).

🌐 **Live Demo (Firebase Hosting):** [https://happy-fly-travel.web.app](https://happy-fly-travel.web.app)

---

## 🚀 Стек технологий

- **Next.js 16.4.6** (App Router, Turbopack, статический экспорт `output: 'export'`)
- **React 19** + **TypeScript**
- **Tailwind CSS 3.4**
- **Lucide Icons**
- **Firebase Hosting** (мгновенная доставка через CDN)

---

## ✨ Ключевой функционал

- 🌍 **Мультиязычность**: Полная поддержка 3-х языков (`RU`, `UZ`, `EN`) с мгновенным переключением через React Context без перезагрузки страницы.
- 🎨 **Современный премиальный дизайн**:
  - Карточки преимуществ с золотыми акцентами и микроанимациями.
  - Карточки услуг и направлений с модальным окном бронирования тура.
  - Интерактивный 3-шаговый виджет оплаты с конвертером валют (USD ↔ UZS) и поддержкой UZCARD, HUMO, Visa, Mastercard, UnionPay, PayPal.
- 📱 **Форма заявки**: Маска телефонного номера Узбекистана (`+998`), выбор направления и отправка.
- ⚡ **Высокая производительность**: Оптимизированная статическая сборка, мгновенная загрузка.

---

## 🛠️ Запуск проекта локально

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

### Сборка и деплой

```bash
# Сборка проекта
npm run build

# Деплой в Firebase Hosting
firebase deploy --only hosting
```
